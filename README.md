# fedelimd.com

Single static page for fedelimd.com, hosted on GitHub Pages.

- `index.html`: the page. Edit the text here and push to update the site.
- `CNAME`: tells GitHub Pages which custom domain to serve.
- `.nojekyll`: skips the Jekyll build step since this is plain HTML.

DNS is managed at Hover. Email for the domain is Google Workspace and is unrelated to this repo.
